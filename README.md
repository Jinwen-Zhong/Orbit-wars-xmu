# Orbit Wars XMU

Course project for Kaggle Orbit Wars.

## Project Goal

We aim to build a modular Orbit Wars agent using:

- rule-based decision logic
- expansion scoring
- attack and defense safety checks
- parameter tuning
- optional machine-learning action ranking

The project will be evaluated through ablation experiments, replay analysis, and a final 20-minute presentation.

## Repository Structure

```text
agents/         bot versions
core/           shared feature, scoring, safety, and action utilities
experiments/    scripts for evaluation and parameter tuning
models/         machine learning models or model notes
results/        experiment outputs and figures

slides/         presentation materials
