# ML Attempt: Action Ranking

## Goal

We do not use machine learning to directly control the whole bot. Instead, we try to use a lightweight model to rank candidate actions generated by heuristic rules.

## Possible Features

- distance from source planet to target planet
- source_ships
- target_ships
- target_production
- reserve_after_send
- target_owner: neutral or enemy

## Output

The model predicts whether a candidate action is worth taking, or gives it a score.

## Decision

If the ML version is unstable or not better than the tuned heuristic bot, we will not use it as the final bot.
